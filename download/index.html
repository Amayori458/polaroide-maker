Polaroid Maker

Monta fotos em molduras polaroid automaticamente

⬇ Baixar Polaroid Maker

Windows · não precisa instalar Python · ~60 MB

Aviso do Windows na primeira vez: como o programa não é assinado digitalmente, o Windows SmartScreen pode mostrar "O Windows protegeu seu PC". Isso é normal para programas internos. Clique em "Mais informações" e depois em "Executar assim mesmo".
  1. Baixe o arquivo acima.
  2. Dê dois cliques nele pra abrir — não precisa instalar nada.
  3. Escolha a pasta de fotos, o molde (Imã, Grade simples, etc.) e clique em Processar pasta.
